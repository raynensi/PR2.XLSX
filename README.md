# 📊 PR.2 Analyzer — Sales Data Analysis Dashboard

### Turning Raw Sales Data into Meaningful Business Insights

A Microsoft Excel data analysis project focused on exploring customer purchases, analyzing sales and profit, identifying high-value customers, and presenting business insights through PivotTables, charts, statistical analysis, and an interactive-style dashboard.

---

## 📌 Project Overview

**PR.2 Analyzer** is an Excel-based sales analytics project designed to transform raw transactional data into meaningful information for business decision-making.

The project uses Excel formulas, What-If Analysis, regression, descriptive statistics, PivotTables, and visual charts to understand sales performance, customer behavior, regional performance, and profitability.

The final dashboard brings key performance indicators (KPIs) and visual summaries together in one place.

---

## 🎯 Project Objectives

- Analyze total sales, profit, quantity, and customer purchases.
- Identify the top 10 customers based on total sales.
- Estimate how changes in discount rates may affect profit.
- Study the relationship between Sales and Profit using linear regression.
- Generate descriptive statistics for numerical data.
- Analyze monthly sales trends and growth.
- Summarize sales by region and product category.
- Build a clean, professional Excel dashboard.

---

## 🗂️ Dataset Description

The dataset contains **200 sales records** with the following fields:

| Column | Description |
|---|---|
| Customer_ID | Unique customer identifier |
| Customer_Name | Customer name |
| Region | Sales region |
| Product_Category | Category of product sold |
| Sales | Sales amount |
| Quantity | Number of units purchased |
| Discount | Discount applied to the transaction |
| Order_Date | Date of the order |
| Profit | Profit recorded for the transaction |

---

## 📈 Project Tasks and Analysis

### 1. Top 10 Customer Analysis
Identified the highest-value customers by aggregating sales for each Customer_ID and ranking customers by total sales.

### 2. What-If Discount Analysis
Estimated how reducing the discount by five percentage points could affect profit, assuming other costs and sales volume remain unchanged.

### 3. Linear Regression: Sales vs Profit
Used Excel's Analysis ToolPak to examine the relationship between Sales and Profit.

**Regression results:**

| Metric | Result |
|---|---:|
| Observations | 200 |
| R Square | 0.5982 |
| Adjusted R Square | 0.5961 |
